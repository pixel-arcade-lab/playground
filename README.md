# Pixel Arcade

Small browser games and experiments, built step by step.

**Live site (all games):** https://pixel-arcade-lab.github.io/playground/

## Projects

| Project | Play it | What it is | Code |
|---|---|---|---|
| City Walker — Kyoto | [Play now](https://pixel-arcade-lab.github.io/playground/projects/city-walker/) | A third-person walk around a pixel-art Kyoto school, with rooms to enter, sound effects and a map. Built with [Three.js](https://threejs.org/). | [projects/city-walker](projects/city-walker/) |
| Sky Strike — Flight | [Play now](https://pixel-arcade-lab.github.io/playground/projects/flight-sim/) | Take off from a runway and fly a propeller plane or a jet over two islands (village, volcano, waterfall, ring course) with simple mouse-aim controls. Needs a mouse. | [projects/flight-sim](projects/flight-sim/) |
| JJK Verse — Night of Curses | [Play now](https://pixel-arcade-lab.github.io/playground/projects/jjk-verse/) | A 2D pixel-art platformer inspired by Jujutsu Kaisen: run, jump and punch cursed spirits, with combos, Black Flash timing and secret rooms. Built with [Phaser](https://phaser.io/). Needs a keyboard. | [projects/jjk-verse](projects/jjk-verse/) |

## Run it on your own computer

No install needed except Python (only used as a simple local web server):

```bash
python -m http.server 8000
```

Then open http://localhost:8000/ in your browser. Press Ctrl + C in the terminal to stop.
