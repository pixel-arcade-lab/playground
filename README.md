# Pixel Arcade

Small browser games and experiments, built step by step.

**Live site (all games):** https://pixel-arcade-lab.github.io/playground/

## Projects

| Project | Play it | What it is | Code |
|---|---|---|---|
| City Walker — Kyoto | [Play now](https://pixel-arcade-lab.github.io/playground/projects/city-walker/) | A third-person walk around a pixel-art Kyoto school, with rooms to enter, sound effects and a map. Built with [Three.js](https://threejs.org/). | [projects/city-walker](projects/city-walker/) |
| Sky Strike — Flight | [Play now](https://pixel-arcade-lab.github.io/playground/projects/flight-sim/) | Fly a jet over a mountain island with simple mouse-aim controls: point where you want to go and the plane flies there. Needs a mouse. | [projects/flight-sim](projects/flight-sim/) |

## Run it on your own computer

No install needed except Python (only used as a simple local web server):

```bash
python -m http.server 8000
```

Then open http://localhost:8000/ in your browser. Press Ctrl + C in the terminal to stop.
