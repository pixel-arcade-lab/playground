# Kartik's Playground

Small browser games and experiments, built step by step.

**Live site:** https://kartik-823.github.io/playground/

## Projects

| Project | What it is |
|---|---|
| [City Walker — Kyoto](projects/city-walker/) | A third-person walk around a pixel-art Kyoto school, with rooms to enter, sound effects and a map. Built with [Three.js](https://threejs.org/). |

## Run it on your own computer

No install needed except Python (only used as a simple local web server):

```bash
python -m http.server 8000
```

Then open http://localhost:8000/ in your browser. Press Ctrl + C in the terminal to stop.
